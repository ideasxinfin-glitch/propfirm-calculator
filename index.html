El modelo, sin letra pequeña

Una fase de evaluación, seguida por una cuenta fondeada nueva con saldo inicial reiniciado. Aprobación: alcanzar el target después de los días mínimos. Límite de evaluación y horizonte fondeado son independientes. No se compran reintentos. DLL = pérdida realizada desde el inicio del día; tocar un límite causa pérdida de la cuenta.

Static: suelo fijo. EOD: el máximo al cierre diario eleva el suelo. Intraday: el máximo después de cada operación eleva el suelo. El trailing no tiene tope y no se reinicia tras retirar. No se modelan fluctuaciones dentro de una operación, slippage, noticias, consistencia, escalado ni cambios de reglas.

Retiros al cierre cada N días fondeados: mínimo entre beneficio sobre el saldo inicial menos buffer, distancia al suelo menos buffer y tope. Ese importe se descuenta del saldo; recibes el porcentaje de profit split. EV = retiros recibidos − costes de evaluación − activaciones, para todas las cuentas. ROI = beneficio neto esperado / coste esperado. El saldo no retirado no cuenta como ingreso.

Trades Bernoulli de tamaño fijo, win rate y R:R constantes; días independientes. La correlación configurada es la correlación entre resultados binarios de cuentas en el mismo trade de calendario, mediante una mezcla de shocks compartidos. No es una estimación de tu estrategia. Aumentar cuentas correlacionadas no diversifica de forma equivalente a cuentas independientes.

Modelo ilustrativo, no predicción ni asesoría financiera. Verifica las reglas vigentes directamente con cada firma. Los resultados dependen de los supuestos; una simulación favorable no garantiza retiros.

Intervalo de aprobación: aproximación normal 95%, conservadora con cuentas correlacionadas (N = simulaciones de cartera). Los resultados Monte Carlo tienen error de muestreo. Ningún dato sale de este navegador; se guardan configuraciones localmente cuando está disponible.

# PropFirm Calculator

Calculadora web autónoma con Monte Carlo reproducible. Abre index.html o usa GitHub Pages desde la raíz del repositorio. Sin dependencias ni instalación.

Incluye evaluación, drawdown static/EOD/intraday por trades cerrados, DLL, payouts, múltiples cuentas correlacionadas, EV, ROI y comparaciones. Consulta los supuestos dentro de la interfaz. Presets ficticios: verifica las reglas de tu firma.

Los cálculos se ejecutan localmente en el navegador. No se requieren claves ni servicios externos.
